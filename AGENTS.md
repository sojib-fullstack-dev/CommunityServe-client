<!-- ===== Next.js version notice =====
This project uses Next.js 16.4.3. APIs, conventions, and file structure may differ from older versions. The relevant guide is at `node_modules/next/dist/docs/`.
===== development commands =====

- `npm run dev` — starts the development server (Turbopack by default)
- `npm run build` — builds the app for production
- `npm run start` — runs the production server
- `npm run lint` — runs ESLint

===== build / test / lint order =====

- Run `lint` before `build`/`dev` to catch errors early.
- There is no separate test script; tests are written with Jest/React Testing Library (see `jest.config.js` if present).

===== project structure =====

- `app/` — Next.js app router directory. `page.tsx` is the home route, `layout.tsx` is the root layout.
- `components/ui/` — shadcn/ui component library. Generated/managed via `npx shadcn@latest add <component>`.
- `components/` — root-level components (re-exports from `components/ui` via path aliases).
- `hooks/` — custom React hooks (`use-mobile.ts`, `use-highlighted-code.ts`).
- `lib/` — utilities (`highlighter.tsx` for shiki-based code highlighting, `utils.ts` re-exports `cn`).
- `public/` — static assets.

===== key conventions & quirks =====

- **Tailwind CSS v4** — config is in `next.config.ts`. Tailwind rules are under `turbopack` in `next.config.ts`. CSS is in `app/globals.css`. The `components.json` defines the shadcn pipeline (`style: "base-nova"`, `baseColor: "neutral"`).
- **Path aliases** — `@/*` maps to `.//*` (tsconfig.json). Use `@/...` imports rather than relative paths.
- **shiki code highlighting** — `lib/highlighter.tsx` loads languages on demand. `useHighlightedCode` hook in `hooks/use-highlighted-code.ts` wires it up. Languages listed: bash, css, diff, html, javascript, json, jsx, markdown, python, sql, tsx, typescript, yaml.
- **Font optimization** — `next/font` is used to load Geist/Geist Mono automatically (no manual font loading needed).
- **ESLint** — config in `eslint.config.mjs`. Extends `eslint-config-next` with some global ignores (`.next/`, `out/`, `build/`, `next-env.d.ts`).

===== shadcn/ui workflow =====

- Add a component: `npx shadcn@latest add <component-name>`
- Components are in `components/ui/` and imported via `@/components/ui/<Component>`.

===== important notes =====

- The `.next/` directory is generated by Next.js and is git-ignored.
- `components.json` is the manifest for shadcn component management.
- Tailwind CSS v4 has a significantly different API than v3 — do not reference v3 docs.
