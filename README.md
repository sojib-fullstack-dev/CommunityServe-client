# CommunityServe

CommunityServe is a community-driven social development platform where people can create, discover, and join social service events to make a positive impact in their communities.

https://community-serve-omega.vercel.app


## GitHub Repositories

- **Client Side:** https://github.com/sojib-fullstack-dev/CommunityServe-client
- **Server Side:** https://github.com/sojib-fullstack-dev/CommunityServe-Server

## Features

- **Authentication:** Secure user registration and login using Better Auth.
- **Create Events:** Logged-in users can create social development events.
- **Upcoming Events:** Explore upcoming community service events.
- **Join Events:** Users can join events and track their participation.
- **Manage Events:** Users can update and delete their own created events.
- **Protected Routes:** Secure private pages and APIs using JWT authentication.
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Dark/Light Theme:** Switch between light and dark modes.

## Technology Stack

### Frontend
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Node.js
- Express.js
- MongoDB

### Authentication
- Better Auth
- MongoDB Adapter
- JWT

## Getting Started

### 1. Clone Client Repository

```bash
git clone https://github.com/sojib-fullstack-dev/CommunityServe-client.git
cd CommunityServe-client
npm install
npm run dev
```

### 2. Clone Server Repository

```bash
git clone https://github.com/sojib-fullstack-dev/CommunityServe-Server.git
cd CommunityServe-Server
npm install
npm run dev
```

### 3. Environment Variables

Configure the required environment variables in your `.env` files for MongoDB, authentication, JWT, and API connections.
